# Imágenes de aneker.es

Esta carpeta contiene las imágenes de la web. Si falta alguna, la web muestra un recuadro con la indicación (no es un error).

## Imágenes esperadas

### Portada
- **portada.jpg** (horizontal, ~2100×900 px)
  - Descripción: Oficina real, archivo o personas trabajando con documentos
  - Formato: JPG
  - Peso máximo: 300 KB

### Equipo
- **equipo.jpg** (vertical 4:5, retrato)
  - Descripción: Foto del equipo, retrato natural en entorno de trabajo
  - Formato: JPG
  - Peso máximo: 300 KB

### Herramientas
- **thejtool.png** (captura de pantalla, 16:10)
  - Descripción: Captura real de TheJTool
  - Formato: PNG
  - Peso máximo: 300 KB

### Cuaderno (artículos)
- **articulo-1.jpg** - Persona revisando documentos en papel
- **articulo-2.jpg** - Estanterías de archivo
- **articulo-3.jpg** - Planificación de un proyecto en una pizarra
- **articulo-4.jpg** - Facturas sobre una mesa

**Formato:** JPG  
**Dimensiones:** Ancho máximo 2100 px  
**Peso máximo:** 300 KB cada una

## Optimización

Cuando añadas imágenes:
- Redimensiona al ancho máximo necesario (2100 px)
- Comprime para que no superen 300 KB
- Usa formatos JPG para fotos, PNG para capturas de pantalla
